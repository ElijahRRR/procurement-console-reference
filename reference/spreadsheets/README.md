# 参考导入与导出

两份 Excel 只含表头，按原列序重新建立；不包含隐藏工作表、历史单元格、批注、地址或支付数据。它们描述参考系统的格式，不是本项目已实现的导入接口。

- [采购导入模板](采购导入模板.xlsx)：来自小蜜蜂公开的 [Amazon 导入模板](https://smallbee168.com/amazon_order_template.xlsx)。其中“平台订单号”指上游业务标识；“AMZ订单号”指实际供应方订单。买家号与买家号 ID 不同。
- [订单物流导出表头](订单物流导出表头.xlsx)：由两份现有订单物流导出工作簿的首行交叉核对生成。保留“付款卡号”等原列名用于兼容性对照，未提供任何真实值；该列不代表新系统要采集或输出完整卡号。此格式不可与物流查询接口返回的九字段 JSON 混用。
